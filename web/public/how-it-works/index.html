How it works

  1. 1

    Overlap years

    From 2012 both sensors watched the same fires. MODIS on Aqua and VIIRS on S-NPP pass at the same time of day (about 1:30 pm and 1:30 am).

  2. 2

    Conversion factor

    For each country and calendar month we measure VIIRS hotspots per MODIS hotspot. A small area gets its own factor, pulled toward the country value when it has few detections: k = (V + λ·kcountry) / (M + λ).

  3. 3

    Old record on the new scale

    MODIS months before 2012 become VIIRS-equivalent hotspots with an error range. Each month is then compared with the same month in other years.

Data flow

History (2003 → last month) comes from NASA FIRMS yearly archive files and the FIRMS API, rebuilt automatically every month. The newest days come from the FIRMS API every 3 hours. Why not fetch 20 years on every click?

S-NPP stopped on 2 Nov 2026. Live data come from NOAA-20 (same VIIRS instrument), converted to the S-NPP scale with a measured factor (×0.97).
