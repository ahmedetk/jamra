Data acknowledgment

We acknowledge the use of data and/or imagery from NASA's Fire Information for Resource Management System (FIRMS) (https://earthdata.nasa.gov/firms), part of NASA's Land, Atmosphere Near real-time Capability for Earth observations (LANCE) (https://earthdata.nasa.gov/lance) and NASA's Earth Science Data and Information System (ESDIS).

  • MODIS Collection 6.1 active fire (Terra, Aqua) and VIIRS 375 m active fire (S-NPP, NOAA-20), standard processing: FIRMS yearly files and FIRMS API.
  • VIIRS NOAA-20 near real time: FIRMS API, every 3 hours.

Use of artificial intelligence (AI)

We used an AI coding assistant (Claude Code by Anthropic) to write the code for the data pipeline, the website and the live system, following our design and decisions. The team chose the method, checked results against NASA FIRMS data and verified every reference.

Our demo video was made with AI tools, and its voice-over is AI-generated (ElevenLabs).
