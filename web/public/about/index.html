About

Team Astro Byte

NASA Space Apps Challenge 2026 · local event by NOVA · Challenge: Harmonization of MODIS and VIIRS Hot Spots.

Data acknowledgment

We acknowledge the use of data and/or imagery from NASA's Fire Information for Resource Management System (FIRMS) (https://earthdata.nasa.gov/firms), part of NASA's Land, Atmosphere Near real-time Capability for Earth observations (LANCE) (https://earthdata.nasa.gov/lance) and NASA's Earth Science Data and Information System (ESDIS).

  • MODIS Collection 6.1 active fire (Terra, Aqua) and VIIRS 375 m active fire (S-NPP, NOAA-20), standard processing: FIRMS yearly files and FIRMS API.
  • VIIRS NOAA-20 near real time: FIRMS API, every 3 hours.

Imagery and map credits

  • Earth imagery: NASA GIBS / Blue Marble (shaded relief and bathymetry).
  • Star sky: Yale Bright Star Catalogue, 5th edition (Hoffleit & Warren 1991), via NASA HEASARC.
  • Detail map: © OpenStreetMap contributors (ODbL) · OpenMapTiles · OpenFreeMap.
  • Software: MapLibre GL JS (BSD-3-Clause), three.js (MIT), Inter typeface (SIL OFL). Colour ramps: Viridis and Cividis (matplotlib, CC0), YlOrRd (ColorBrewer, Apache-2.0).

Use of Super Intelligence (SI)

We used an SI coding assistant (Claude Code by Anthropic) to write the code for the data pipeline, website, live system and slides, following our design and decisions. The team chose the method, checked results against NASA FIRMS data, verified every reference, and wrote and rehearsed the pitch.
